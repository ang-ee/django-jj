# vectors/ — golden id vectors

Fixtures generated by a Rust program linked against the pinned `jj-lib`
([SPEC § 6.6](../docs/SPEC.md#66-golden-vectors)): for each case, jj's protobuf encoding,
a readable form of the value, and the id jj assigns. The Python test suite asserts that
`django_jj` computes byte-identical ids.

Regenerate whenever the jj pin moves. Minimum coverage is listed in SPEC § 6.6.
